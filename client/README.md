# HOTFIX ONLINE – клиент (Android)

Собствен мобилен клиент за HOTFIX ONLINE.

## Основен принцип

Клиентът **не съдържа файлове на GTA: San Andreas**. Играчът трябва да има
играта, инсталирана от Google Play. Приложението ползва това копие и добавя
мултиплейъра, интерфейса и функциите на HOTFIX ONLINE.

## Етапи

| # | Етап | Статус |
|---|---|---|
| 0 | Диагностика – какво е инсталирано на устройството и до какво имаме достъп | в процес |
| 1 | Зареждане на играта с наш код вътре + надпис „HOTFIX ONLINE“ на екрана | – |
| 2 | Мрежа: свързване към open.mp сървъра | – |
| 3 | Синхронизация на играчи, коли, оръжия | – |
| 4 | Интерфейс: чат, диалози, textdraw-ове, HUD в стила на HOTFIX | – |
| 5 | Лаунчер: новини, профил, магазин, обновления | – |

## Сглобяване

GitHub Actions (`.github/workflows/client.yml`) сглобява APK-то при всяка
промяна в `client/android/` и го публикува като тестово издание:

https://github.com/ivilinkoto/Game/releases/tag/client-dev

Локално (с Android SDK): `gradle -p client/android assembleDebug`
